## 🚀 Features

### 🌐 Network Tools
* **Website Analyzer & Scanner:** Analysiere URLs und Sicherheits-Header.
* **Port Scanner & Pinger:** Überprüfe die Erreichbarkeit und offene Ports.
* **IP Analyzer:** Detaillierte Informationen über IP-Adressen.

### 🔍 OSINT (Open Source Intelligence)
* **Username & Email Search:** Finde Profile über verschiedene Plattformen.
* **Phone & IP Lookup:** Identifiziere Standorte und Provider-Daten.

## 💻 Installations-Guide (CMD) **Easy way**

Folge diesen Schritten in deinem `Explorer`, um das Tool zu starten:

1. **Erforderungen Überprüfen**
    Stelle sicher, dass Python installiert ist.
        Zum Testen öffnest du dein `CMD` und und gibst die Folgenden Befehle ein:

    `Standard-Befehl:` "python --version"
    `Zweiter-Befehl:` "python3 --version"
    `Alternativ-Befehl:` "py -0"

    Wenn Du Python Installiert hast, Sollte etwas Da Stehen Wie `"Python 3.13.7"`
    Dann Kannst du Zum Zweiten Punkt Gehen. Wenn nicht, dann musst du Python installieren.

    Geh auf https://www.python.org/downloads/ und installiere Python Rest kannst du auf Youtube Suchen.

2. **Requirements Installieren**
    - Öffne deinen Windows-Explorer und geh in den Ordner, in dem deine `SurrealTools.py` und requirements.txt liegen.
    - Klicke oben in die Adressleiste (da, wo der Pfad steht, z. B. `C:\Users\Name\Desktop\SurrealTools`).
    - Lösche den Text dort, tippe einfach cmd ein und drücke Enter.
    - Es öffnet sich sofort ein schwarzes Fenster, das bereits im richtigen Ordner ist.

    - Sobald das schwarze Fenster (CMD) offen ist, gibst du einfach den, unten angezeigten Befehl ein.
        `pip install -r requirements.txt`
    - Sollte die Fehlermeldung kommen, dass "pip" nicht gefunden wurde, versuche es mit diesem Befehl.
        `python -m pip install -r requirements.txt`
2. **Programm Starten**
    Öffne `SurrealTools.py`im ordner oder über CMD mit python `SurrealTools.py`

    Passwörter sind weiter unten fürs tool
